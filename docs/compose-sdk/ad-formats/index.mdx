# Ad Formats

All five formats are reached the same way, through the singleton:

```kotlin
val ads = AdMobManager.getInstance(application)
val interstitialAdLoader = ads.interstitialAdLoader
val rewardedAdLoader = ads.rewardedAdLoader
val appOpenAdLoader = ads.appOpenAdLoader
// Banner and Native are Composables — you don't reach a loader object for
// these directly in UI code, see their pages below.
```

Every load/show method takes an `AdPlacementKeys` constant, an optional
`point` (for per-call-site blocking — see
[Remote Config](/compose-sdk/remote-config#per-point-control)), and resolves
the real ad unit ID from Remote Config internally. There is no raw-ad-unit-ID
"manual" path documented here the way the XML SDK has one — every loader in
this SDK is placement-first by design.

## Quick picker

| I want to... | Use |
|---|---|
| Monetize a natural break in the flow (finished action, level, share) | [Interstitial](/compose-sdk/ad-formats/interstitial) `loadAndShowAdForPlacement` |
| Reward a user for opting in to watch a video | [Rewarded](/compose-sdk/ad-formats/rewarded) |
| Keep a small ad visible while the user reads/scrolls | [Banner](/compose-sdk/ad-formats/banner) — `BannerType.ADAPTIVE` |
| Get a higher-CTR block ad on an article/blog screen | [Banner](/compose-sdk/ad-formats/banner) — `BannerType.MEDIUM_REC` |
| Save vertical space on a tight layout | [Banner](/compose-sdk/ad-formats/banner) — `BannerType.COLLAPSABLE` |
| Blend an ad into a list/feed with your own layout | [Native](/compose-sdk/ad-formats/native) — `NativeAd()` + slot Composables |
| Drop in a native ad without building a layout | [Native](/compose-sdk/ad-formats/native) — `NativeAdCard()` |
| Monetize app cold start or return-from-background | [App Open & Resume](/compose-sdk/ad-formats/app-open-resume) |
| Show a loading dialog while any of the above loads | [Loading Dialog](/compose-sdk/loading-dialog) |
